AI & HR classroom project

AI-Powered Performance Appraisal & Language Analysis

Classroom project using fictional data

I explored how four AI agents and Python language checks could help a manager prepare and examine an employee performance review. The goal was to highlight wording that might need clearer evidence while keeping decisions in human hands.

  • Agent workflow: Organized notes, drafted an appraisal, checked wording, and prepared for a feedback conversation.
  • Python analysis: Screened gender-associated terms, trait versus behavior patterns, and differences in feedback specificity.
  • Comparison: Examined why an AI reviewer and fixed-rule scanners reached different findings on the same fictional appraisal.

My contribution: I set up the agents using the provided instructions and manually transferred information and outputs between stages. The agents did not automatically communicate with one another.

One finding: Agent 3 flagged ten phrases, including “demonstrating a solid understanding of the work required,” because it described an impression without an observable example. The Python gender-wording scanner flagged its word-stem matches, while the other two scanners passed their classroom thresholds.

What I learned: A statement such as “missed two meetings” is more informative than calling someone “unreliable.” I learned to check the evidence behind a flag rather than accept automated judgments as proof of bias.

Limitations: These tools examine wording, not whether a manager's account is accurate or fair. The thresholds are classroom screening rules, and the results do not establish discrimination or proven time savings.

Part 1: Explore my four-agent workflow

Each agent had a separate responsibility. I entered the instructions and moved information manually. In this workflow, the draft was sent separately to the Bias Checker and Conversation Coach.

Key safeguards: Agent 1 and Agent 2 were instructed not to invent performance details. Agent 3 was instructed to name the potential issue and quote exact wording. Agent 4 helped prepare a supportive but honest discussion. These are rules from the agent instructions, not proof that every output followed them perfectly.

Part 2: Explore my Python NLP analysis and results

The Python notebook used word-stem matching for gender-associated terms, grammar-based rules for trait and behavioral language, and sentiment plus evidence markers for specificity. These were screening checks, not a model I trained.

  • Gender-associated wording — flagged: 11 matched communal word stems and no agentic matches (100% of matched stems, not 100% of the review).
  • Trait versus behavior — passed: 0% trait-only among sentences counted by that rule.
  • Specificity — passed: 16.7 percentage-point difference under the classroom's 40-point flagging threshold.

Agent 3 comparison: It rated overall wording risk as medium and flagged ten passages. Unlike the Python trait scanner, Agent 3 flagged a trait-like description; unlike the Python gender-stem scanner, Agent 3 did not identify a meaningful gender-coded concern. A disagreement is a reason to check the wording and context, not proof either tool is right.

Important limit: Words like “collaboration” and “support” can simply describe job duties. A word match by itself does not establish bias.
